# Alta Pulse — Extensão para Google Chrome

Monitore presença, turnos e atendimento dos chatters direto no Chrome que eles já usam
para acessar a Privacy. Sem instalar programa, sem bloqueio do Windows e sem usar a API
da Privacy.

## Como instalar (modo desenvolvedor — grátis)

1. Baixe e **descompacte** esta pasta em um local fixo do computador.
2. No Chrome, abra `chrome://extensions`.
3. Ligue o **Modo do desenvolvedor** (canto superior direito).
4. Clique em **Carregar sem compactação** e selecione esta pasta.
5. Fixe o ícone Alta Pulse na barra, clique nele e entre com seu acesso Alta Pulse.

## Como distribuir para a equipe (Chrome Web Store — US$ 5, uma vez)

1. Crie a conta em https://chrome.google.com/webstore/devconsole (taxa única de US$ 5).
2. Compacte esta pasta em um `.zip` e faça upload.
3. Marque a visibilidade como **Não listada** e publique.
4. Compartilhe o link com a equipe: instalação com um clique e atualização automática.

## Privacidade

- Não lê mensagens, não copia cookies e não usa nenhuma API da Privacy.
- Envia ao painel somente: presença na Privacy, criadora atendida, turno e horários observados.
- Login e verificações na Privacy continuam manuais, na conta do próprio chatter.
